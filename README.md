## Project

### SecureShip Gate
Multi-agent **release readiness & security review coach**, built in IBM Bob IDE.

| Piece | What |
|-------|------|
| Problem | Pre-release reviews are slow (2–4h), serial, and miss critical risks |
| Solution | Parallel Bob subagents (security / deps / tests / rollback) → go/no-go report |
| Bob features | Agent mode, parallel tasks, subagents, document understanding, code reviews |
| Evidence | `bob_sessions/` task session summary screenshots |
| Metrics | Review time ~2h → 15–20 min; seeded critical findings caught |

## Why not a pure A2A bridge?

BGI HyperSprint owns `a2a-omega` (agent-to-agent messaging). This Bob submission is a **different product** focused on a *developer workflow* (release/review) where Bob IDE is the core engine. Sharing infrastructure ideas is fine; submitting the same project to both events is not.
